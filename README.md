# カウンター

5項目を数えられるシンプルなカウンターです。円グラフ・棒グラフで割合を確認できます。

- ＋／－ボタンでカウント、↻ボタンで項目ごとにリセット
- 円グラフ・棒グラフ、％／実数表示の切り替え、合計表示
- 設定画面で項目名・色・値・グループ名を編集
- データはブラウザ（localStorage）に保存

## 公開 (GitHub Pages)

`main` に push すると `.github/workflows/pages.yml` が GitHub Pages にデプロイします。
初回はリポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。
